# HoverCard

A richer hover panel for content too large for a tooltip.

Use for org previews and summary cards on hover. Use `Tooltip` for a short label.

`tip` must be wrapped in `HoverCardContent`; `children` must be a single element that can take a ref. Neither this nor `Tooltip` takes an `open` prop — both own their open state.
