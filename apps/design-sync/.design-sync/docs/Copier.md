# Copier

A click-to-copy control for a short string.

Use for EINs, wallet addresses and referral links. `text` is what gets copied; children are what is shown.
Without children the trigger is a bare icon, so it carries the name "Copy"; pass `label` where a row holds more than one copier and "Copy" alone doesn't say which thing. With children the visible text is the name — leave `label` off.
