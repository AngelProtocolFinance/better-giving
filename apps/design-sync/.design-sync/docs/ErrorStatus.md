# ErrorStatus

An error message with an alert icon, in the destructive color.

For a failed load or action. Keep the copy direct and non-apologetic: 'We couldn't reach the payment processor'. Never 'Oops!'.

`StatusProps` also declares `inline` and `gap`, but this component forwards only `classes` and `children` — setting them does nothing. Use `classes` for spacing.
