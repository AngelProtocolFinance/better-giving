# PasswordInput

A password input with a show/hide reveal toggle.

Takes `error` like the other fields. The reveal control is built in.

`label` renders the field's own label, wired to the input and the reveal toggle — pass it rather than a separate `Label`. Set `autoComplete="new-password"` on a signup or reset field so the password manager offers to generate one; the default suits a sign-in field.
